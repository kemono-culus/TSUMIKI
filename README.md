# TSUMIKI

**Scratch学習者のためのイラスト素材配布サイト**

TSUMIKI（つみき）は、小学生のScratch学習者や、その指導者に向けたイラスト素材配布サイトです。

自作のイラスト素材を提供し、Scratchを使ったプログラミング学習や作品制作を支援します。

## サイト

- **公開サイト：** https://kemono-culus.github.io/TSUMIKI/
- **利用規約：** https://kemono-culus.github.io/TSUMIKI/pages/rule/

## 主な機能

- イラスト素材の一覧表示
- ジャンル・カテゴリによる絞り込み
- イラストのプレビュー
- 画像ファイルのダウンロード
- 利用規約の確認
- 素材ごとのダウンロード数の集計

## 素材の利用について

TSUMIKIでは、Scratchでの作品制作に使用することを前提として、自作のイラスト素材を配布しています。

素材の利用には独自の利用規約を設けています。利用可能な範囲や禁止事項などの詳細については、必ず以下のページをご確認ください。

**[TSUMIKI 利用規約](https://kemono-culus.github.io/TSUMIKI/pages/rule/)**

※ 素材の利用条件と、本リポジトリのソースコードの利用条件は別のものです。

## 技術構成

本サイトは、HTML・CSS・JavaScriptを中心に構成された静的Webサイトです。

| 技術 | 用途 |
|---|---|
| HTML | ページの構造・コンテンツの表示 |
| CSS | ページのレイアウト・デザイン |
| JavaScript | 素材一覧の生成、絞り込み、ダウンロードなどの動作 |
| Google Apps Script | ダウンロード情報の受信・集計処理 |
| Google スプレッドシート | ダウンロード履歴の記録・集計 |
| GitHub Pages | Webサイトの公開・ホスティング |

## 素材の管理

イラスト素材はZIP形式でリポジトリに追加し、管理用のスプレッドシートに登録したものをJSON形式で取得しています。

登録された情報をもとに、JavaScriptで素材一覧を動的に生成する仕組みです。そのため、通常の素材追加ではHTMLやJavaScriptを直接変更する必要はありません。

管理している主な情報は以下のとおりです。

- 素材の通番
- 素材ID
- 素材名
- ジャンルコード
- タグ
- 一言コメント
- 投稿日

素材IDは、固定されたディレクトリ構成のもとで、実質的に素材ファイルのパスとしても機能します。

## ダウンロード数の集計

素材のダウンロード操作が行われると、JavaScriptからGoogle Apps Scriptを介してGoogleスプレッドシートへ情報を送信します。

送信する情報は、ダウンロード対象の素材IDとタイムスタンプです。

記録した情報は、素材ごとのダウンロード数や利用傾向の大まかな分析に活用しています。

この集計機能は外部サービスとの連携に依存するため、サイト本体の表示機能とは別に動作します。

## 開発・動作確認

本サイトはGitHub Pagesで公開しています。

通常の更新では、ローカル環境でファイルを編集し、GitHubへ変更をプッシュして公開します。

ローカル環境で動作確認する場合は、ローカルサーバーを使用してください。HTMLファイルを直接ブラウザで開く方法では、一部のJavaScriptが正しく動作しない場合があります。

また、Google Apps Scriptとの連携を含む機能については、公開環境での動作確認も必要です。
